# Claim Citation Map

This file maps the major claims in `website_copy_draft.md` and `explainer_notebook_text.md` to supporting project artifacts or external sources. The goal is to keep the final website and notebook honest: every story claim should be backed by an artifact, official source, or clearly framed limitation.

## How to Use This Map

- Use **artifact finding** claims for project-specific numbers and chart interpretations.
- Use **official rule** sources for parking rules, violation codes, camera programs, ASP, meters, and fine tables.
- Use **official financial report** sources only for official DOF context. Do not mix DOF official totals with the cleaned project count.
- Use **external context** sources for broader curb-management or data-limitations framing.
- Use **limitation** rows to avoid overclaiming.
- Claims marked **maybe** are usable only with the conservative wording in the notes.
- Claims marked **no** should not appear as positive claims in the final website or notebook.

## Conservative Rewrites for Risky Claims

Use these rewrites when polishing the website and notebook:

- Instead of: **"The data is a map of illegal parking."**  
  Use: **"The data maps the enforcement footprint of issued tickets."**

- Instead of: **"Precinct 0 is fake data."**  
  Use: **"Precinct 0 is analytically important, but it is not normal geography."**

- Instead of: **"High-ticket precincts have the worst parking behavior."**  
  Use: **"High-ticket precincts carry a larger share of issued-ticket records."**

- Instead of: **"Estimated fine value is revenue."**  
  Use: **"Estimated fine value is an analytical estimate from issued tickets, not collected revenue."**

- Instead of: **"Different precincts are targeted by different rules."**  
  Use: **"Different violation families are more prominent in different precincts."**

- Instead of: **"This proves parking enforcement is unfair."**  
  Use: **"This proves uneven issued-ticket geography and rule mix, not causal unfairness."**
