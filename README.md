# The Uneven Curb

DTU Social Visualization final project.

The public website is in `site/`. The root `index.html` redirects to `site/` so GitHub Pages can be served from the repository root.

## GitHub Pages Files

- `index.html` - root redirect for GitHub Pages
- `site/index.html` - final public website
- `site/styles.css` - website styles
- `site/script.js` - small website interactions
- `site/figures/` - Plotly HTML figures used by the site
- `site/docs/` - copied material packet, captions, references, and claim checks
- `analysis_github.ipynb` - stripped-output explainer notebook for GitHub
- `Parking_Violations_Issued_Data_Dictionary.xlsx` - data dictionary

The raw FY2025 parking violations CSV is not included because it is too large. Use the NYC Open Data link in the website references.
